# Practice Missions

수업 시간에 바로 써먹을 수 있는 문제 모음입니다.

## 공통 미션

- 모든 파일에서 모델 이름을 바꿔 보고 차이를 기록해 보세요.
- 시스템 프롬프트를 짧게 썼을 때와 길게 썼을 때의 차이를 비교해 보세요.
- 오류가 났을 때 어떤 메시지가 보이는지 읽고 원인을 추측해 보세요.

## 01 기본 생성

- 자기소개를 해 주는 프롬프트로 바꿔 보세요.
- "중학생이 이해할 수 있게" 라는 조건을 추가해 보세요.
- 답변을 3문장으로 제한해 보세요.

## 02 reasoning effort

- 수학 문제, 추론 문제, 글쓰기 문제를 하나씩 만들어 보세요.
- 각 effort 에서 답변 속도와 답변 질을 비교해 보세요.
- 어떤 문제에서는 minimal 로도 충분한지 토론해 보세요.

## 03 temperature

- 설명형 질문 하나와 창작형 질문 하나를 준비하세요.
- 어떤 temperature 값이 각 질문에 어울리는지 적어 보세요.
- 답변의 독창성, 안정성, 반복성 관점에서 평가해 보세요.

## 04 web search

- "오늘" 또는 "최근" 이 들어가는 질문으로 바꾸세요.
- 최신 IT 뉴스, 스포츠 결과, 날씨 중 하나를 선택해 질문해 보세요.
- 검색 도구가 왜 필요한지 한 문장으로 정리해 보세요.

## 05 custom tool

- `CLASSROOM_DATA` 에 새로운 항목을 2개 추가해 보세요.
- `category` 대신 `topic` 이라는 이름으로 바꿔 보세요.
- 모델이 tool 을 잘 호출하지 않으면 description 을 더 구체적으로 고쳐 보세요.

## 06 OpenRouter + Qwen

- 같은 질문으로 thinking on/off 결과를 비교해 보세요.
- temperature 를 0.2, 0.8, 1.2 로 바꾸어 보세요.
- OpenAI reasoning effort 와 Qwen thinking 의 차이를 자기 말로 정리해 보세요.

## 07 터미널 챗봇 기본

- 챗봇 이름과 성격을 정해 보세요.
- "선생님 모드", "친구 모드", "과학자 모드" 중 하나를 정해 시스템 프롬프트에 반영하세요.
- 이전 대화를 잘 기억하는지 질문을 이어 가며 테스트해 보세요.

## 08 명령어 챗봇

- `/summary` 명령어를 직접 추가해 보세요.
- `/save` 파일 이름에 현재 날짜와 시간을 넣어 보세요.
- `/reset` 전에 정말 초기화할지 묻도록 바꿔 보세요.

## 09 스트리밍 챗봇

- 답변이 길수록 스트리밍이 왜 더 자연스럽게 느껴지는지 적어 보세요.
- 스트리밍 중간에 줄바꿈이 너무 많으면 어떻게 다듬을지 생각해 보세요.
- 일반 응답 방식과 스트리밍 방식의 장단점을 비교해 보세요.

## 웹 챗봇

- 첫 화면 환영 문구를 바꿔 보세요.
- 추천 프롬프트 카드 내용을 바꿔 보세요.
- 답변 길이 제한, 말투, 역할을 시스템 프롬프트에서 조절해 보세요.
- 채팅 기록을 파일이나 브라우저 저장소에 보관하는 기능을 추가해 보세요.
- Enter 로 전송, Shift+Enter 로 줄바꿈이 되도록 동작을 확인해 보세요.
